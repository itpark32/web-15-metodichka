# Дальше по программе

<p class="reading-time">Карта следующих модулей без подмены пройденного материала</p>

Программа курса 2026 года рассчитана на 18 месяцев. Эта версия методички заканчивается на темах, которые подтверждаются папкой 15 потока. Следующие главы стоит добавлять после появления учебных примеров и проектов.

## Текущая граница JavaScript

Методичка теперь завершает актуальный блок темами Web Storage, обработкой исключений, HTTP и REST API, ООП, ES-модулями и устройством SPA. Следующий крупный переход начинается с React и TypeScript.

## React и TypeScript

По программе идут компоненты, JSX, props, state, хуки, Context, Redux Toolkit, React Router, формы, API, React Query, TypeScript и тестирование. Для этого блока нужна отдельная серия глав и проект, где эти механизмы используются вместе.

## Подготовка к работе

Программа включает GitHub-профиль, портфолио, резюме, тестовые задания, HR-этап и техническое интервью. Текущая методичка уже начинает этот маршрут через [вопросы](interview/index.md) и [разбор проектов](projects.md).

## Дополнительный backend-модуль

PHP, MySQL и Laravel являются дополнительным модулем. Они не входят в текущую методичку, потому что в материалах потока нет подтверждения их прохождения.

    Новая глава появляется, когда есть материал занятия, рабочий пример и мини-задача. Название темы в общей программе само по себе не означает, что тема пройдена.
