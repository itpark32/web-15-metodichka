# Пробное интервью

<p class="reading-time">45 минут · теория, код и разбор проекта</p>

Попросите одногруппника задавать вопросы по порядку и уточнять «почему?». Не открывайте методичку до завершения блока.

## Разминка, 8 минут

1. Что происходит от ввода URL до отображения HTML?
2. Зачем нужна семантика?
3. Как браузер вычисляет итоговый CSS?
4. Когда выбрать Flexbox, а когда Grid?
5. Когда изображение должно быть `img`, а когда фоном?

## JavaScript, 10 минут

1. Назовите типы данных и способы их проверить.
2. Объясните разницу между примитивом и объектом при копировании.
3. Сравните `map`, `filter`, `reduce` и `forEach`.
4. Объясните область видимости, замыкание и `this`.
5. Расскажите порядок выполнения синхронного кода, Promise и таймера.
6. Как найти причину `NaN` и чем его правильно проверить?
7. В каком месте вы перехватите ошибку, а в каком пробросите дальше?

## Браузер, сеть и архитектура, 8 минут

1. Чем DOM отличается от BOM?
2. Когда выбрать `localStorage`, а когда `sessionStorage`?
3. Из чего состоят HTTP-запрос и ответ?
4. Почему Fetch не считает 404 сетевой ошибкой?
5. Как ES-модули помогают разделить код SPA?

## Практика, 12 минут

Реализуйте функцию:

```js
function summarizeOrders(orders) {
  // вернуть { total, paidCount }
}
```

Входные данные:

```js
const orders = [
  { id: 1, amount: 900, status: "paid" },
  { id: 2, amount: 1500, status: "new" },
  { id: 3, amount: 700, status: "paid" },
];
```

Уточнения интервьюера:

- что вернуть для пустого массива;
- как обработать неверный `amount`;
- меняется ли исходный массив;
- какова временная сложность;
- как проверить функцию несколькими примерами.
- как сообщить об ошибке, не скрывая ее пустым `catch`.

## Проект, 7 минут

Выберите калькулятор, слайдер или один из больших макетов и расскажите:

1. какую задачу решает проект;
2. как разделен код;
3. какое состояние хранится;
4. где была самая сложная ошибка;
5. что вы изменили бы для доступности и надежности.
6. как проверяли соответствие макету и запросы во вкладке Network.

## Оценка

| Уровень | Признак |
|---|---|
| Нужна доработка | определение вспоминается только с подсказкой |
| База есть | определение и пример верны, но нет объяснения механизма |
| Уверенный ответ | есть механизм, пример и частая ошибка |
| Сильный ответ | есть ограничение, альтернатива и аргумент выбора |

После прогона запишите не «не знаю JavaScript», а конкретный пробел: «путаю `target` и `currentTarget`» или «не проверяю `response.ok`». Вернитесь ровно к нужной главе.
