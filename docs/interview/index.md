# Подготовка к собеседованию

<p class="reading-time">Вопросы только по темам, подтвержденным материалами 15 потока</p>

Вопросы отобраны по разделам HTML, CSS и JSCore сайта [my-interview.tech](https://www.my-interview.tech/). Методичка не копирует большой каталог, а превращает знакомые темы в короткий маршрут повторения.

## Шаблон сильного ответа

<div class="answer-pattern" markdown>

**Определение → механизм → пример → ограничение.**

«Делегирование событий использует всплытие. Один обработчик на общем контейнере проверяет `event.target` и обрабатывает подходящий потомок. Это удобно для динамических списков, но не подходит событиям, которые не всплывают».

</div>

## Как тренироваться

1. Прочитайте только вопрос.
2. Дайте ответ за 45-90 секунд.
3. Покажите пример из 3-8 строк кода.
4. Назовите частую ошибку или ограничение.
5. Откройте подсказку и уточните ответ.

## Маршрут подготовки

| Блок | Что проверить | Практика |
|---|---|---|
| HTML | семантика, формы, ссылки, подключение ресурсов | объяснить структуру страницы |
| CSS | каскад, box model, Flexbox, Grid, адаптивность | сверстать небольшой блок |
| JavaScript | типы, коллекции, функции, область видимости | решить задачу у доски |
| Браузер | DOM, события, формы, Event Loop, Fetch | разобрать интерактивный сценарий |
| Git и инструменты | коммит, ветка, конфликт, сборка | описать путь изменения до публикации |

!!! tip "Не учите формулировку"
    Интервьюер меняет условия и задает уточняющие вопросы. Запоминайте причинно-следственную связь и подтверждайте ее кодом.
